# 📁 Organizador Automático de Arquivos

Aplicativo desenvolvido em Python com interface gráfica utilizando Tkinter, que automatiza a organização de arquivos em pastas de acordo com suas extensões.

## 🚀 Funcionalidades

- Seleção de diretório pelo usuário.
- Identificação automática das extensões dos arquivos.
- Criação automática de pastas por categoria.
- Organização de imagens, documentos, vídeos, áudios, arquivos compactados e outros.
- Movimentação automática dos arquivos.
- Interface gráfica intuitiva.
- Relatório da quantidade de arquivos organizados.

## 🛠️ Tecnologias utilizadas

- Python
- Tkinter
- OS
- Shutil

## 📋 Requisitos

- Python 3 instalado.
- Tkinter disponível na instalação do Python.

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Entre na pasta do projeto:

```bash
cd organizador-de-arquivos
```

3. Execute o programa:

```bash
python organizador.py
```

## 📚 Objetivo

Projeto desenvolvido para praticar manipulação de arquivos e diretórios, automação de tarefas, utilização de bibliotecas nativas do Python e desenvolvimento de interfaces gráficas.

## ⚠️ Observação

O programa movimenta os arquivos para as pastas correspondentes. Recomenda-se testar inicialmente em uma pasta com arquivos de exemplo.
